================================================================================
KEY CONCEPTS / GOTCHAS
================================================================================
- 3 line-id systems: schematic keys '1'..'12','B1' <-> graph route ids KT1/KT2/KS/
  ER6/ER7/AG/SP/KJ/KG/MR/PY/BRT <-> normalized ids KJ/MRT/PYL/AG/PH/MR/BRT/KT1/KT2/
  KS/ER6/ER7 (route_colors).
- KTM lines (KT1,KT2,KS) + KLIA (ER6,ER7) are NOW VISIBLE on the map (only line '11'
  Johan Setia remains hidden in map_screen.dart _hiddenLineIds). Colors in route_colors.
- Transit map background = assets/images/klang_valley_map.jpeg (interactive_schematic_map
  loads it; falls back to grey grid canvas if missing).
- ETA is pinned once (<100m from origin) -> definitive arrival clock time; counts
  down from pinnedArrivalTime. On arrival submits trip_feedback (predicted/actual).
  fetchEtaCorrection() (crowd_reports_service) reads historical trip_feedback
  deviation_min for the route and nudges the pinned ETA -> continual learning.
- Backend supabase pin is 2.31.0 (2.9.0 had a "Invalid API key" JWT-regex bug that
  broke snapshot_daily_blend cron).
- Supabase free tier auto-pauses after 7 days inactivity (keepalive workflow).
- Config lives in app/env/dev.json (JSON), NOT .env. Env vars override.
